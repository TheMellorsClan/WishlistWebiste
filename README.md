# Wishlist

A small browser-based wishlist app for saving product links, prices, notes, categories, priorities, images, and purchased status.

Double-click `Wishlist.app` or `Open Wishlist.command` to run it. The launcher starts a small local server and opens the app in your browser.

If you already added items while using `index.html` directly, export that list as a PDF first, then use the PDF restore code in the launched version.

## Features

- Keep separate Wishlist and Projects areas
- Create separate projects inside the Projects area
- Add items with a product link and notes
- Edit, delete, and mark items as purchased
- Filter by category or status
- Search and sort the list
- Export a PDF-ready wishlist with images, links, prices, descriptions, and categories
- Import JSON backups or restore from a PDF restore code
- Uses the bundled OpenDyslexic font throughout the app and PDF export
